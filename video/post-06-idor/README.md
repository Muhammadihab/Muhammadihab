# بوست ٦: فيديو IDOR

الموشن جرافيك كله متعمل بالكود (HTML/CSS/JS) واترندر فريم فريم: ‏1080×1920، ‏30fps، ‏45 ثانية.

## الملفات الجاهزة (`out/`)

| الملف | استخدامه |
|---|---|
| `post06_preview.mp4` | معاينة: الجرافيكس + المؤثرات الصوتية، ومكانك فيه صورة رمزية |
| `post06_greenscreen.mp4` | نفس الفيديو، بس مكانك **أخضر صافي `#00FF00`**. حطّه فوق الكليب بتاعك وشيل الأخضر بـ Chroma Key (في CapCut أو Premiere) |
| `sfx.wav` | المؤثرات الصوتية لوحدها (whoosh، pop، click…)، ومسيبة مساحة للصوت |
| `cues.md` | مكان الكاميرا ووقت كل punch-in على وشّك |

## مكانك في الفيديو

- **Split** (أغلب الوقت): المستطيل اللي تحت `x=64, y=1030, 952×490`
- **PiP دايرة صغيرة** (من 23 لـ 28 ثانية ومن 34 لـ 39 ثانية): `x=770, y=1272, 248×248`

## لما الصوت يجهز

1. ابعت الصوت (أو الصوت والكليب بتاعك مع بعض).
2. هظبط التوقيتات على كلامك. كلها في سطر واحد: `const S = {...}` في `index.html`.
3. أعيد الرندر، وأركّب الصوت والمؤثرات وكليبك، ويطلع الفيديو النهائي.

## الرندر (للمطوّرين)

```bash
node render.mjs preview frames_preview 4     # فريمات المعاينة
node render.mjs green   frames_green   4     # فريمات الجرين سكرين
python3 sfx.py timeline.json sfx.wav         # المؤثرات الصوتية
# المعاينة المباشرة في المتصفح: index.html?play=1   أو   index.html?t=12.5
```
